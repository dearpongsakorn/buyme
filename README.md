# เงินของฉัน — แอปรายรับรายจ่าย (PWA)

แอปบันทึกรายรับรายจ่ายภาษาไทย ดีไซน์แบบ iOS ตั้งเงินเดือนแล้วคำนวณว่าเดือนนี้ใช้ไปเท่าไหร่ เหลือเท่าไหร่ ใช้ได้อีกวันละกี่บาท และ**ใช้ร่วมกับแฟนได้** — เห็นรายการของกันและกัน แต่งบแยกของใครของมัน

- เว็บไฟล์เดียว ไม่มี build step ไม่มี dependency (คุยกับ Supabase ผ่าน `fetch` ตรงๆ)
- ใช้งานออฟไลน์ได้ (service worker) ติดตั้งลงหน้าจอโฮมได้เหมือนแอปจริง
- โหมดมืดเป็นค่าเริ่มต้น สลับเป็นสว่าง/ตามระบบได้ในหน้าตั้งค่า
- **ไม่เข้าสู่ระบบ** = ข้อมูลอยู่ใน `localStorage` ของเครื่องนั้นเท่านั้น
- **เข้าสู่ระบบ** = ซิงก์ขึ้น Supabase, ใช้ได้หลายเครื่อง, จับคู่กับแฟนด้วยรหัสเชิญ 6 หลัก, บันทึกตอนเน็ตหลุดแล้วซิงก์ให้เองเมื่อกลับมาออนไลน์

## ขึ้น Vercel ผ่าน GitHub

### 1. สร้าง repo บน GitHub

เข้า https://github.com/new → ตั้งชื่อ เช่น `money-app` → เลือก Public หรือ Private ก็ได้ → **ไม่ต้องติ๊ก** Add README / .gitignore → Create repository

### 2. push โค้ดขึ้นไป

แตกไฟล์ zip นี้แล้วรันในโฟลเดอร์ (โค้ด commit แรกเตรียมไว้ให้แล้ว):

```bash
git remote add origin https://github.com/<ชื่อผู้ใช้ของคุณ>/money-app.git
git branch -M main
git push -u origin main
```

ถ้ายังไม่มี git history (เช่นแตก zip แล้วโฟลเดอร์ `.git` หาย) ให้รันชุดนี้แทน:

```bash
git init
git add .
git commit -m "feat: money tracker PWA"
git remote add origin https://github.com/<ชื่อผู้ใช้ของคุณ>/money-app.git
git branch -M main
git push -u origin main
```

### 3. import เข้า Vercel

1. เข้า https://vercel.com/new
2. เลือก **Continue with GitHub** แล้วกด **Import** ที่ repo `money-app`
3. หน้า Configure Project — **ไม่ต้องแก้อะไรเลย**
   - Framework Preset: `Other`
   - Build Command: เว้นว่าง
   - Output Directory: เว้นว่าง (ใช้ root)
4. กด **Deploy** รอประมาณ 20–30 วินาที

จะได้ลิงก์หน้าตาแบบ `https://money-app-xxxx.vercel.app` — ส่งลิงก์นี้ให้อีกคนใช้ได้เลย

> หลังจากนี้ทุกครั้งที่ `git push` ขึ้น `main` Vercel จะ deploy ใหม่อัตโนมัติ

### 4. (ทางเลือก) ใช้ชื่อโดเมนของตัวเอง

Vercel → Project → Settings → Domains → Add

## วิธีติดตั้งลงมือถือ

**iPhone / iPad (Safari)**
เปิดลิงก์ → ปุ่มแชร์ (⬆️) → เลื่อนหา **เพิ่มไปยังหน้าจอโฮม** → Add

**Android (Chrome)**
เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป** / เพิ่มไปยังหน้าจอหลัก

เปิดจากไอคอนจะได้แบบเต็มจอ ไม่มีแถบเบราว์เซอร์ และใช้ได้แม้ไม่มีเน็ต

## ใช้ร่วมกับแฟน

1. ทั้งคู่เปิดลิงก์เดียวกัน → ตั้งค่า → **เข้าสู่ระบบ / สมัครสมาชิก** → สมัครด้วยอีเมลคนละอัน
2. คนแรก: ตั้งค่า → **ใช้ร่วมกับแฟน** → จะเห็น **รหัสเชิญ 6 หลัก** ส่งให้อีกฝ่าย
3. คนที่สอง: ตั้งค่า → ใช้ร่วมกับแฟน → กรอกรหัสในช่อง "เข้าร่วมด้วยรหัสของอีกฝ่าย" → กดเข้าร่วม

เสร็จแล้วหน้าภาพรวมจะมีสวิตช์ **ของฉัน / ของแฟน / รวมกัน**

| | หมายความว่า |
|---|---|
| ของฉัน | เงินเดือนคุณ เทียบกับรายจ่ายคุณ |
| ของแฟน | เงินเดือนแฟน เทียบกับรายจ่ายแฟน (ดูได้อย่างเดียว) |
| รวมกัน | เงินเดือนสองคนรวมกัน เทียบกับรายจ่ายสองคนรวมกัน |

รายการทุกอันจะมีชื่อ + วงกลมสีบอกว่าใครเป็นคนบันทึก (ฟ้า = คุณ, ส้ม = อีกฝ่าย)
**แก้ไข/ลบได้เฉพาะรายการของตัวเอง** — บังคับที่ฐานข้อมูลด้วย RLS ไม่ใช่แค่ซ่อนปุ่มใน UI

ถ้าอยากแยกกระเป๋าออกจากกัน: ตั้งค่า → ใช้ร่วมกับแฟน → **แยกกระเป๋าออกจากกัน** (รายการของแต่ละคนยังอยู่ครบ)

### ตั้งค่า Supabase (ทำครั้งเดียว จบแล้ว)

โปรเจกต์ที่ใช้อยู่: `nvagsyvueppkjrcyinqu` (ap-southeast-1) — คีย์ที่ฝังใน `index.html` เป็น **publishable key** ซึ่งเปิดเผยได้ตามปกติ ความปลอดภัยอยู่ที่ RLS

**สิ่งเดียวที่ควรเช็ค:** Supabase → Authentication → Sign In / Providers → Email → **Confirm email**

- ปิดไว้ (แนะนำสำหรับใช้กันเอง 2 คน) = สมัครแล้วเข้าใช้ได้เลย
- เปิดไว้ = ต้องกดยืนยันในอีเมลก่อน แล้วค่อยกลับมาเข้าสู่ระบบ (แอปจะขึ้นข้อความบอก)

โครงสร้างตารางและ RLS ทั้งหมดอยู่ใน [`supabase/schema.sql`](supabase/schema.sql) — รันไฟล์นี้ใน SQL Editor ถ้าจะย้ายไปโปรเจกต์ใหม่ แล้วแก้ค่า `CLOUD` ใน `index.html` ให้ตรง

### เรื่องข้อมูล

| คำถาม | คำตอบ |
|---|---|
| ไม่เข้าสู่ระบบได้ไหม | ได้ ใช้แบบเก็บในเครื่องเหมือนเดิมทุกอย่าง |
| สมัครแล้วข้อมูลเก่าหายไหม | ไม่หาย ตอนสมัครครั้งแรกแอปจะย้ายรายการ หมวดหมู่ และเงินเดือนขึ้นคลาวด์ให้ |
| เน็ตหลุดแล้วบันทึกได้ไหม | ได้ รายการจะเข้าคิวและซิงก์เองเมื่อกลับมาออนไลน์ (ดูสถานะที่ ตั้งค่า → สถานะข้อมูล) |
| เห็นรายการของแฟนช้าไหม | แอปดึงข้อมูลใหม่ทุก 25 วินาที และทุกครั้งที่กลับมาเปิดหน้าจอ |
| คนอื่นที่ไม่ได้จับคู่เห็นไหม | ไม่เห็นเลย ทดสอบด้วย RLS แล้ว: คนนอกเห็นเฉพาะข้อมูลตัวเอง |

## ไฟล์ในโปรเจกต์

```
index.html              ตัวแอปทั้งหมด (HTML + CSS + JS ในไฟล์เดียว)
manifest.webmanifest    ข้อมูลแอปสำหรับติดตั้งลงหน้าจอโฮม
sw.js                   service worker สำหรับใช้งานออฟไลน์
vercel.json             ตั้งค่า header / cache ของ Vercel
icons/                  ไอคอนแอป (192, 512, maskable, apple-touch, favicon)
supabase/schema.sql     ตาราง + RLS + ฟังก์ชันจับคู่ (เอกสารอ้างอิง / ใช้ตั้งโปรเจกต์ใหม่)
```

## แก้ไขโค้ด

แก้ `index.html` ไฟล์เดียวจบ เปิดไฟล์ในเบราว์เซอร์เพื่อทดสอบได้ทันที
เมื่อแก้แล้ว **ควรเปลี่ยนเลข `VERSION` ใน `sw.js`** (เช่น `money-v2.0.1`) เพื่อให้เครื่องที่ติดตั้งไว้แล้วดึงเวอร์ชันใหม่
